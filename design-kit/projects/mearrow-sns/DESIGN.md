# MEARROW SNS

## Direction
A media-first K-pop community where fan posts are the primary content and social actions stay easy to reach. The visual system uses MEARROW blue for navigation and actions, deep ink for media contrast, and lime only as a small accent.

## Web source
The server-rendered HTML and its original compiled Next.js stylesheets are transferred from the current MEARROW home route. Desktop, tablet, and mobile behavior comes from the product's own responsive CSS. Feed rows use privacy-safe sample content and local sample media; the markup, class structure, layout, and styling remain source-derived.

## App concept
Native-style concept based on existing public feed, fan voting, and profile capabilities. It has its own bottom navigation and 3-screen flow: feed, vote board, profile. These screens are design proposals, not implemented app functionality.

## Screen inventory
- Web: community feed, fan vote, creator profile
- App: community feed, fan vote, member profile

## Content boundary
Private feed posts, profile images, usernames, and identifiers are replaced with sample values. The page has no live user feed, authentication, voting, comments, or share action. The native-style app pages remain concepts because this repository has no implemented native app source.
