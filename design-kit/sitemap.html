SOURCE RULE

Responsive web and app concepts

Web raw screens are static transfers from the existing MEARROW product code. The repository has no native app source, so app raw screens are concepts based on existing product capabilities. Only the responsive web screens have portfolio exports. All tracks are static and do not connect to product data or APIs.
