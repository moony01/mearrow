# MEARROW Design Assets

Local assets copied from the MEARROW product repository for static kit previews.

- brand/: current MEARROW, MEARROW SNS, and MEARROW Studio vector marks
- studio/: hero and campaign visuals used by Studio
- news/: public editorial thumbnails used as static content examples
- companies/: public company marks used in fan-vote ranking previews

The pages reference only these local assets. No credentials, private user media, or remote API data are included. The inherited upstream placeholder at brand/logo.png is not used by any MEARROW screen.
